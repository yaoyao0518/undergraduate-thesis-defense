## 📖 项目简介
本项目针对游戏行业从“增量市场”转向“存量市场”的背景，采集真实行业新闻与玩家评论，利用**文本挖掘技术**识别行业热点趋势，并分析玩家对游戏产品的情感倾向，为游戏研发与运营提供数据驱动的优化建议。

## 🔍 核心方法与发现
- **数据来源**：36氪游戏行业新闻（数百篇）+ B站米哈游游戏评价视频评论（1.6万+条）。
- **技术链路**：
  - 爬虫：Selenium（动态网页）+ API调用（静态数据）
  - 预处理：中文分词、去停用词、文本清洗
  - 分析：LDA主题建模（困惑度确定6大主题）、TF-IDF+K-Means提取式摘要、BERT微调情感分类（积极/消极）、词云可视化
- **主要结论**：
  - **宏观行业**：提炼出技术创新、监管政策、工作环境、出海与投资、企业并购、AIGC内容生成六大行业热点。
  - **微观用户**：玩家积极情绪主要源于剧情、角色体验与抽卡保底机制；消极情绪集中在重复性“高肝”任务、战斗机制缺乏策略性等痛点，并据此提出了针对性的游戏优化建议。
